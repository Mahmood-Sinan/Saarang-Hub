# Saarang Hub

The project contains frontend and backend for a website where users can login/signup, view events, register/unregister for an event and logout too..

---

# Tech Stack

## Frontend
- React
- JavaScript
- CSS

## Backend
- Node.js
- Express.js

## Database
- MongoDB

---
